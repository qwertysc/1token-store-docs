# Codex Mac 汉化

技术指导可联系QQ 690023772，WX shenchong999

## 一、用途说明

这个教程用于帮助 Mac 用户把 Codex 桌面端英文界面改成中文界面。

## 二、下载汉化工具

请根据你当前的情况选择：

| 当前情况 | 下一步 |
|---|---|
| 还没有安装 Codex | 先打开 <a href="/guide/codex" target="_blank" rel="noopener noreferrer">Codex 安装与配置</a>，完成 Codex 安装和基础配置。 |
| 已经安装 Codex | 继续使用本页下载汉化工具。本页只负责 Mac 版 Codex 界面汉化。 |

1. <a href="https://pan.quark.cn/s/f03713510dfd?pwd=5L4i" target="_blank" rel="noopener noreferrer">夸克网盘下载（提取码：5L4i）</a>

2. <a href="https://pan.baidu.com/s/1GVAaHVL3am1kB-18hVmBTQ?pwd=set3" target="_blank" rel="noopener noreferrer">百度网盘下载（提取码：set3）</a>

## 三、操作步骤

1. 下载完成后，双击 `Codex-mac汉化工具.zip` 解压出 `Codex Mac 汉化.command`。

2. 双击 `Codex Mac 汉化.command`。

3. 如果弹窗提示无法打开或执行失败，请点击“完成”，然后打开系统设置，进入“隐私与安全性”，滑到页面最下面，点击“仍要打开”。回到汉化工具文件夹后，再次双击 `Codex Mac 汉化.command`。
