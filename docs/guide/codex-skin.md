# Codex 换肤

## 这是什么？

Codex 换肤器可以自定义 Codex 的背景和主题，让你和喜欢的人物一起构建项目。

## 一、准备与下载

1. 如果还没有安装 Codex，请先参考 <a href="/guide/codex" target="_blank" rel="noopener noreferrer">Codex 使用</a> 完成安装和基础配置。
2. 下载换肤器并解压：

   - <a href="https://pan.baidu.com/s/1ZJCaalssIq0Qv1OZ7A3oUw?pwd=c9qe" target="_blank" rel="noopener noreferrer">百度网盘下载（提取码：c9qe）</a>
   - <a href="https://pan.quark.cn/s/593b9c0520b0?pwd=uJ56" target="_blank" rel="noopener noreferrer">夸克网盘下载（提取码：uJ56）</a>

## 二、安装换肤器

1. 在 Codex 中打开解压后的换肤器文件夹。

   <a href="/images/codex-skin/codex-skin-01.webp"><img class="guide-image-compact" src="/images/codex-skin/codex-skin-01.webp" alt="在 Codex 中打开换肤器文件夹"></a>

2. 点击项目名称右侧的铅笔图标新建任务，输入下面的指令：

   ```text
   帮我安装这个 Codex 换肤器
   ```

   <a href="/images/codex-skin/codex-skin-02.webp"><img class="guide-image-compact" src="/images/codex-skin/codex-skin-02.webp" alt="让 Codex 安装换肤器"></a>

3. 等待指令执行完毕。安装完成后，换肤器会自动重新打开 Codex，并应用默认主题。

   <a href="/images/codex-skin/codex-skin-03.webp"><img class="guide-image-compact" src="/images/codex-skin/codex-skin-03.webp" alt="Codex 换肤器安装完成后的效果"></a>

4. 如果 Codex 没有自动打开，可在 Windows 开始菜单或 macOS 聚焦搜索中搜索“皮肤启动器”，找到并打开 `HeiGe 皮肤启动器`。以后也建议从这个入口启动 Codex。

   Windows 如果启动时报错，请先选择“打开文件位置”，再右键启动器并选择“以管理员身份运行”。

   <a href="/images/codex-skin/codex-skin-09.webp"><img class="guide-image-compact" src="/images/codex-skin/codex-skin-09.webp" alt="在 Windows 中打开皮肤启动器的文件位置"></a>

   <a href="/images/codex-skin/codex-skin-10.webp"><img class="guide-image-compact" src="/images/codex-skin/codex-skin-10.webp" alt="在 Windows 中以管理员身份运行皮肤启动器"></a>

## 三、设置皮肤

1. 点击 Codex 顶部中间的“主题”，进入皮肤中心。这里可以选择主题、添加自定义图片，也可以开启“皮肤常驻”。

   “皮肤常驻”会尝试让原生 Codex 入口也显示皮肤，但实际效果可能不稳定，建议仍从 `HeiGe 皮肤启动器` 进入。

   <a href="/images/codex-skin/codex-skin-04.webp"><img class="guide-image-compact" src="/images/codex-skin/codex-skin-04.webp" alt="Codex 换肤器主题中心和皮肤常驻设置"></a>

2. 主题中心提供多套内置皮肤，下面是“原神·星夜”的效果。

   <a href="/images/codex-skin/codex-skin-05.webp"><img class="guide-image-compact" src="/images/codex-skin/codex-skin-05.webp" alt="Codex 原神主题皮肤效果"></a>

3. 也可以选择“自定义图片”，这是小朋友最喜欢的迪迦奥特曼皮肤。

   <a href="/images/codex-skin/codex-skin-06.webp"><img class="guide-image-compact" src="/images/codex-skin/codex-skin-06.webp" alt="Codex 自定义图片皮肤效果"></a>

4. 切换皮肤后，如果文字与背景颜色接近、不方便阅读，可打开 Codex 设置，在“外观”中切换浅色或深色模式。

   <a href="/images/codex-skin/codex-skin-07.webp"><img class="guide-image-compact" src="/images/codex-skin/codex-skin-07.webp" alt="在 Codex 外观设置中切换颜色模式"></a>

## 四、恢复换肤器

如果因为版本更新或电脑重启导致皮肤效果未生效，可以在换肤器项目下新开一个会话，输入下面的指令：

```text
帮我恢复换肤器
```

Codex 会帮你自动修复换肤器。

<a href="/images/codex-skin/codex-skin-11.webp"><img class="guide-image-compact" src="/images/codex-skin/codex-skin-11.webp" alt="让 Codex 恢复换肤器"></a>

## 五、清除换肤器

要认真干活了，想清掉这些花里胡哨怎么办？在换肤器项目下新建任务，输入下面的指令：

```text
帮我清除换肤器
```

Codex 会按换肤器项目提供的清理流程恢复原生界面。

<a href="/images/codex-skin/codex-skin-08.webp"><img class="guide-image-compact" src="/images/codex-skin/codex-skin-08.webp" alt="让 Codex 清除换肤器"></a>
